# ユビキタス言語定義

## ドメイン用語の定義
| 用語 | 定義 |
|---|---|
| 売買代金(ばいばいだいきん) | ある1日の「株価(終値) × 出来高」で算出される、その日にその銘柄で取引された金額の合計。チャート表示の参考情報として使うが、売り検討シグナルの判定には使わない。 |
| 出来高(できだか) | ある期間に売買が成立した株数。 |
| 移動平均(いどうへいきん) | 直近N営業日の終値の単純平均。本アプリでは25日線(短期)と75日線(長期)を算出する。売り検討シグナルの判定には25日線のみを使う。 |
| 売り検討シグナル | 前日終値が25日移動平均線の上にあり、当日終値が25日移動平均線を下回った(下抜けた)かどうかで判定する、売却を検討すべきかの指標。「強・なし・判定不可」の3段階で表示する。 |
| ウォッチリスト | 利用者が登録した(最大10件程度の)証券コードの一覧。登録銘柄ごとに売り検討シグナルを一覧比較できる。 |

## ビジネス用語の定義
| 用語 | 定義 |
|---|---|
| 個人投資家 | 本アプリの想定利用者。日本株(東証銘柄)を自己資金で保有し、売買判断を自身で行う個人。 |
| 投資助言ではない | 本アプリが表示するシグナル・チャートはあくまで判断材料であり、売買を推奨・保証するものではないことを示す注記。README・画面上に明記する。 |

## UI/UX用語の定義
| 用語 | 定義 |
|---|---|
| 一覧画面 | ウォッチリストに登録した全銘柄の売り検討シグナルを表形式で比較できる画面。 |
| 詳細画面 | 一覧から選択した1銘柄について、株価チャート・売買代金チャート・シグナル判定理由・データテーブルを表示する画面。 |
| シグナルレベル | 「強(🔴)・なし(🟢)・判定不可(⚪)」で表示するシグナルの状態。アイコンと色で直感的に区別できるようにする。 |

## 英語・日本語対応表
| 英語(コード上の用語) | 日本語(画面・ドキュメント上の用語) |
|---|---|
| code | 証券コード |
| symbol | (yfinance用)ティッカーシンボル |
| turnover | 売買代金 |
| turnover_ratio | 売買代金比率(当日 ÷ 20日平均) |
| ma_short / ma_long | 短期移動平均(25日) / 長期移動平均(75日) |
| sell signal | 売り検討シグナル |
| watchlist | ウォッチリスト |
| level | シグナルレベル(強/なし/判定不可) |
| reasons | シグナルの判定理由 |

## コード上の命名規則
* ドメイン用語は原則として英語(ローマ字転記ではなく意味の英訳)で命名する(例: 売買代金 → `turnover`、証券コード → `code`)
* 上記の対応表にない新しいドメイン用語を追加する場合は、実装前に本ファイルへ追記し、コード上の命名と揃える
