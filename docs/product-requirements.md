# プロダクト要求定義書

## プロダクトビジョンと目的
日本株(東証銘柄)を保有する個人投資家が、「いつ売るべきか」を感覚ではなくデータに基づいて判断できるよう支援するダッシュボードを提供する。

売買代金(株価×出来高)の急増と株価チャート(移動平均線)の動きという2つの客観的な指標を組み合わせ、売り時の目安を可視化することで、感情的な売買判断を減らすことを目指す。

**本プロダクトは投資助言を行うものではなく、あくまで判断材料を提供するツールである。**

## ターゲットユーザーと課題・ニーズ
* **ターゲットユーザー**: 日本株を保有する個人投資家(自分自身)。投資経験は浅く、テクニカル指標の細部よりも「今売るべきか」をシンプルに把握したい。
* **課題**:
  * 保有銘柄の売り時を判断する明確な基準がなく、感覚に頼っている
  * 出来高や売買代金の異常な動きに気づきにくい
  * 複数の指標を毎回自分でチャートから読み取るのが手間
* **ニーズ**: 保有銘柄をまとめて登録し、売り時の目安(シグナル)と根拠となるチャート・数値をひと目で確認したい。

## 主要な機能一覧
1. 複数銘柄コード(最大10件程度)の一括入力による株価・出来高データの取得(東証銘柄、`.T`サフィックス)
2. 登録した全銘柄の売り検討シグナルを一覧比較できるウォッチリスト表示
3. 一覧から選択した銘柄の株価チャート表示(ローソク足 + 25日/75日移動平均線)
4. 選択した銘柄の売買代金の推移表示(棒グラフ + 20日移動平均)
5. 売り検討シグナルの判定・表示(強/中/弱/なし の4段階、銘柄ごとに算出)
   * 売買代金の急増(20日平均の2倍以上)を主指標とする
   * 高値圏(直近60日高値の95%以上)での急増をより強いシグナルとして扱う
   * 移動平均のデッドクロス(25日線が75日線を下回る)を補助シグナルとする
6. 選択した銘柄の直近20営業日分の指標データテーブル表示

## 成功の定義
* 保有銘柄の証券コードを入力してから、売り時シグナルとその根拠を確認するまでの一連の操作が迷わず行える
* シグナルの根拠(なぜそう判断したか)が画面上の説明文で明確に分かる
* 自分の売買判断の参考として継続的に利用できる状態を維持できる

## ビジネス要件
* 個人利用が前提であり、収益化は対象外
* 無料で利用できるデータソース(yfinance)を使用し、APIキー等の契約は不要とする
* ブラウザで動作するダッシュボード形式(Streamlit)とする

## ユーザーストーリー
* 投資家として、保有する複数銘柄の証券コードをまとめて登録したい。それにより、毎回1銘柄ずつ入力し直す手間を省けるから。
* 投資家として、登録した銘柄を一覧でシグナルの強さ順に比較したい。それにより、どの銘柄から確認すべきかすぐ判断できるから。
* 投資家として、一覧から気になる銘柄を選んで詳細チャートを見たい。それにより、シグナルの根拠を自分の目でも確認できるから。
* 投資家として、シグナルが「なぜ」表示されているのかの理由を確認したい。それにより、シグナルを鵜呑みにせず自分で納得して判断できるから。

## 受け入れ条件
* 証券コードを最大10件程度まとめて入力すると、登録した全銘柄の売り検討シグナルが一覧表示される
* 一覧から銘柄を1つ選択すると、その銘柄の株価チャート・売買代金チャート・シグナル判定理由が表示される
* 存在しない、またはデータが取得できない証券コードが含まれる場合、その銘柄だけエラー表示とし、他の銘柄の表示は継続される
* シグナルが「強」「中」「弱」のいずれかの場合、判定理由が箇条書きで表示される
* 表示期間(6ヶ月/1年/2年)を切り替えられる
* 上限(10件)を超える証券コードを入力しようとした場合、分かりやすいメッセージで上限を伝える

## 機能要件
* FR-1: カンマ区切り等で複数の証券コード(最大10件)を入力できる
* FR-2: 各証券コード(4桁の数字など)からyfinance用シンボルへの変換を行う
* FR-3: 指定した表示期間の日次OHLCV(始値・高値・安値・終値・出来高)データを銘柄ごとに取得する
* FR-4: 銘柄ごとに売買代金・売買代金移動平均・株価移動平均(25日/75日)・直近高値を算出する
* FR-5: 銘柄ごとに売買代金急増および移動平均デッドクロスの条件に基づき、売り検討シグナル(強/中/弱/なし/判定不可)と判定理由を算出する
* FR-6: 登録した全銘柄のシグナルを一覧表示し、シグナルの強さで並び替えられる
* FR-7: 一覧から選択した銘柄について、ローソク足チャート、売買代金チャート、直近20営業日のデータテーブルを表示する

## 非機能要件
* データ取得に失敗した場合、アプリ全体がクラッシュせずエラー内容を画面に表示する
* データ提供元(yfinance/Yahoo Finance)の障害・仕様変更の影響を受けやすいことを許容し、致命的エラー時は分かりやすいメッセージを表示する
* 個人利用の範囲であり、大量アクセスや同時多接続は想定しない
* 特別なインフラ(サーバー常時起動、データベース等)を必要とせず、ローカル環境で `streamlit run app.py` を実行するだけで動作すること
