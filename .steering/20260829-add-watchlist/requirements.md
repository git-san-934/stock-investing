# 要求内容: ウォッチリスト機能の追加

## 変更・追加する機能の説明
現状の単一銘柄入力を、証券コードを最大10件程度まとめて入力できるウォッチリスト形式に変更する。入力した全銘柄の売り検討シグナルを一覧比較できる画面を追加し、一覧から選択した銘柄の詳細(チャート・売買代金・シグナル理由)を表示する。

## ユーザーストーリー
* 投資家として、保有する複数銘柄の証券コードをまとめて登録したい。それにより、毎回1銘柄ずつ入力し直す手間を省けるから。
* 投資家として、登録した銘柄を一覧でシグナルの強さ順に比較したい。それにより、どの銘柄から確認すべきかすぐ判断できるから。
* 投資家として、一覧から気になる銘柄を選んで詳細チャートを見たい。それにより、シグナルの根拠を自分の目でも確認できるから。

(`docs/product-requirements.md` のユーザーストーリー・受け入れ条件と同一)

## 受け入れ条件
* 証券コードを最大10件程度まとめて入力すると、登録した全銘柄の売り検討シグナルが一覧表示される
* 一覧から銘柄を1つ選択すると、その銘柄の株価チャート・売買代金チャート・シグナル判定理由が表示される
* 存在しない、またはデータが取得できない証券コードが含まれる場合、その銘柄だけエラー表示とし、他の銘柄の表示は継続される
* 上限(10件)を超える証券コードを入力しようとした場合、分かりやすいメッセージで上限を伝える

## 制約事項
* `docs/architecture.md` の技術的制約(yfinanceの非公式性、永続化なし、東証銘柄限定)を踏襲する
* 既存の `stock_signals.py` の関数(`to_ticker_symbol` / `fetch_price_history` / `compute_indicators` / `evaluate_sell_signal`)のシグネチャは変更しない(1銘柄ずつ呼び出す設計を維持し、ループ制御はUI層で行う)
* 過剰なモジュール分割は行わず、`app.py` と `stock_signals.py` の2ファイル構成を維持する(`docs/repository-structure.md` の方針に準拠)
