# stock-investing

日本株(東証)の売り時判断を支援するダッシュボードです。売買代金の急増を主指標、株価チャート(移動平均のデッドクロス)を補助指標として、売り検討シグナルを表示します。

**投資助言ではありません。** 表示される内容を参考に、最終的な売買判断はご自身で行ってください。

## セットアップ

```bash
python3 -m venv .venv
source .venv/bin/activate  # Windowsは .venv\Scripts\activate
pip install -r requirements.txt
```

## 起動方法

```bash
streamlit run app.py
```

ブラウザが自動で開きます。サイドバーの入力欄に証券コードを、改行またはカンマ区切りで最大10件程度まとめて入力してください(例: `7203, 9984, 6758`)。登録した全銘柄の売り検討シグナルが一覧表示され、一覧から銘柄を選ぶとその銘柄の株価チャート・売買代金・シグナル判定理由が表示されます。

## シグナルの考え方

- **売買代金の急増**: 当日の売買代金(株価 × 出来高)が直近20日平均の2倍以上になった場合に「急増」と判定します。特に直近60日の高値圏(高値の95%以上)で急増した場合はより強いシグナルとして扱います。
- **移動平均のデッドクロス**: 25日移動平均線が75日移動平均線を下回った場合に補助シグナルとして加点します。

これらを組み合わせて「強・中・弱・なし」の4段階でシグナルを表示します。ロジックは `stock_signals.py` にまとまっているので、しきい値や条件は自由に調整してください。
