# stock-investing

日本株(東証)の売り時判断を支援するダッシュボードです。株価が25日移動平均線を下回ったかどうかをもとに、売り検討シグナルを表示します。

**投資助言ではありません。** 表示される内容を参考に、最終的な売買判断はご自身で行ってください。

## セットアップ

```bash
python3 -m venv .venv
source .venv/bin/activate  # Windowsは .venv\Scripts\activate
pip install -r requirements.txt
```

## 起動方法

```bash
streamlit run app.py
```

ブラウザが自動で開きます。サイドバーの入力欄に証券コードを、改行またはカンマ区切りで最大10件程度まとめて入力してください(例: `7203, 9984, 6758`)。登録した全銘柄の売り検討シグナルが一覧表示され、各銘柄の詳細欄を開くと株価チャート・売買代金・シグナル判定理由・過去データでのシミュレーションが表示されます。

## シグナルの考え方

- **25日移動平均線割れ**: 株価(終値)が25日移動平均線を下回った場合に「強」シグナルとして表示します。

シグナルは「強・なし・判定不可」の3段階で表示します。ロジックは `stock_signals.py` にまとまっているので、条件は自由に調整してください。
